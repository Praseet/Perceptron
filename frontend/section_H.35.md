# H.35 Accessibility of color semantics

Color mappings must always have text.

Examples:

```text
✓ validated
✗ rejected
Online
Offline
Fraud
Legit
High
Critical
```

Do not communicate:

```text
green = good
red = bad
```

without text.

This applies to:

- heatmap cells,
- badges,
- SHAP bars,
- status pills,
- loop active-leg styling.
